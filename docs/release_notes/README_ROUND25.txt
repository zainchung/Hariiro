Hariiro — Round 25 (2026-11-22, part of release 1.1.0)

- New installer: extract the ZIP and double-click Install-Hariiro.cmd. It adds
  Panels UI (reborn) and JS Panel (bundled, MIT) when foobar2000 does not have
  them yet, copies the skin and starts foobar2000. On the first start choose
  "Panels UI (reborn)", then View > Panels UI > Skins > Hariiro.
- New ZIP layout: the skin is in the Hariiro folder; components\, preview\
  (screenshots) and THIRD-PARTY-NOTICES.txt sit next to it.
- foobar2000 itself is not bundled (its licence allows sharing only the
  unmodified installer).

See docs/ROUND25_REVIEW.md.
