Hariiro — Round 23 (2026-11-21), release 1.0.0

- The skin is now called Hariiro.
- Settings and the skin's own playlists of earlier test builds are not carried
  over: the skin starts with its defaults and creates "Hariiro - ..." playlists.
  Old playlists stay as normal playlists; copy your favourites by hand.
- The second bundled wallpaper is now 2560 x 1440.

Install into a new, empty skin folder (for example foo_ui_panels-skins\Hariiro).
See docs/ROUND23_REVIEW.md.
