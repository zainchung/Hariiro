Anna Glass V2 — Round 12 test skin

Installation: back up your previous Anna Glass skin and foobar2000 playlists before replacing files.

Dragging:
- Artist / playlist sidebar: use the row's left music-note/grip, drag horizontally RIGHT out of the sidebar to the QUEUE. Vertical list dragging never exports the entire playlist.
- Glass middle panel: selecting/repositioning within the panel does not initiate OLE. Deliberately drag selected tracks across the left/right edge for Queue or target playlist.
- Left sidebar playlist labels can be dragged vertically to reorder playlists (no songs copied).

Queue behavior:
- Upper-right Queue button now CLEARS the playback queue. No confirmation.
- For preservation on manual song changes, in foobar2000 open Preferences > Advanced > Playback and uncheck "Flush playback queue on manual track change". The option is enabled by default in the player; it cannot be changed from the skin's JavaScript API.

Window: double-click the blank top bar area between navigation and library search to maximize/restore.

Do NOT delete profile/playlists-v2.0/*.sqlite directly; these are managed by foobar2000.
See docs/ROUND12_REVIEW.md for changes and test limitations.
