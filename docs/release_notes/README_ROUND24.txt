Hariiro — Round 24 (2026-11-22)

- Fixed: files dragged from File Explorer onto the Queue while Music Library was
  selected were not queued. They are queued now; the Music Library view stays as
  it was. If another component's lock makes foobar2000 create a new playlist for
  the files, they are queued and that playlist is removed.
- Sidebar: Ctrl + click / Shift + click select several playlists; Delete removes
  them (one Undo for all of them).
- Ctrl+Z undoes the last removal of playlists, tracks (middle list) or Queue
  entries, with the focus in the sidebar, the middle list or the Queue. The
  middle list now also shows an Undo notice after removing tracks.
