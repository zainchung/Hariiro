Hariiro — version 1.0.1 (2026-11-28) — 日本語の説明

foobar2000 用の透明な「ガラス」スキンです。

ライセンス：MIT License（このパッケージの LICENSE を参照）。Copyright (c) 2026 zainchung。
スクリプト、レイアウト、壁紙を含む同梱のすべての画像に適用されます。

動作環境
- foobar2000 v2、64 ビット（2.26.3 で確認）。通常インストール版・ポータブル版のどちらでも可：
  https://www.foobar2000.org/（同梱していません。ライセンス上、再配布できるのは
  改変していないインストーラーだけです）
- Panels UI (reborn) 1.27.1 と JS Panel (foo_js_panel) 1.9.2：components\ に同梱
  （MIT ライセンス、THIRD-PARTY-NOTICES.txt を参照）。インストーラーが追加します
- 任意：ESLyric (x64)。歌詞のダウンロードとデスクトップ歌詞に使います

ZIP の中身
- Hariiro\                 スキンフォルダー
- Install-Hariiro.cmd      インストーラー（処理は Install-Hariiro.ps1 が行います）
- components\              Panels UI (reborn) と JS Panel、およびそのライセンス
- preview\                 スクリーンショット

インストール
1. foobar2000 をインストールして一度起動します。（すでに foobar2000 を使っている
   場合は、先に profile、特に playlists-v2.0 フォルダーをバックアップしてください。）
2. ZIP 全体を任意のフォルダーに展開し、Install-Hariiro.cmd をダブルクリックします。
   foobar2000 を見つけ、終了する前に確認し、Panels UI (reborn) と JS Panel が
   まだなければ追加し（インストール済みのものは置き換えません）、Hariiro\ を
   <profile>\foo_ui_panels-skins\Hariiro にコピーして（既存の Hariiro フォルダーは
   先に Hariiro.backup-<日時> としてコピーします）、foobar2000 を起動します。
   foobar2000 の設定やプレイリストは一切変更しません。
   foobar2000 が特殊な場所にある場合：先に foobar2000 を起動してからインストーラーを
   実行するか、次を実行します：
   powershell -ExecutionPolicy Bypass -File Install-Hariiro.ps1 -FoobarDir "<フォルダー>"
3. コンポーネント追加後の初回起動では、2 回クリックします：
   a. 「New user interface module(s) found」で「Panels UI (reborn)」を選び、OK。
   b. Panels UI は最初に独自のレイアウトウィザードを開きます。メニューの
      View > Panels UI > スキン（英語表示では Skins、最後の項目）> Hariiro を選びます。foobar2000 は
      この選択を記憶します。

手動インストール（インストーラーを使わない場合）：2 つのコンポーネントを入れ
（components\<名前>\<名前>.dll を <profile>\user-components-x64\<名前>\ にコピーするか、
公式の .fb2k-component ファイルを使います）、Hariiro フォルダーを
<profile>\foo_ui_panels-skins\ にコピーしてから手順 3 を行います。<profile> は
ポータブル版なら foobar2000.exe の隣の profile フォルダー、通常版なら
%APPDATA%\foobar2000-v2 です。

元に戻す：<profile>\foo_ui_panels-skins\Hariiro を削除し、Hariiro.backup-<日時> の
名前を Hariiro に戻します（必要なら profile のバックアップも戻します）。

言語の切り替え
- メニューボタン ☰（右上、ウィンドウボタンの隣）> スキンの言語 から、English、
  Español、Português、简体中文、繁體中文、日本語、Français、Deutsch、Русский を
  選びます。「システムに合わせる（既定）」は Windows の表示言語を使います。
- 変更はすぐに Hariiro のすべてのラベル、通知、メニューに反映され、再起動後も
  保持されます。
- foobar2000、Panels UI、ESLyric 自身のメニュー（foobar2000 のメニューバー、中央
  リストのメニュー内の曲コマンド、設定画面）は foobar2000 の言語のままです。

使い方
上部バー
- アーティスト / プレイリスト：左のサイドバーを、ライブラリのアーティストと自分の
  プレイリストで切り替えます。再生中：再生中の曲へ移動します。
- 検索ボックス：入力して Enter でライブラリを検索し、結果はサイドバーの
  「Search Result」に入ります。ボックス内で Ctrl+A / Ctrl+C / Ctrl+V が使えます。
  右クリックで 今すぐ検索、クリップボードから貼り付け、検索をクリア。
- ☰：Hariiro 設定：ミニプレーヤー（下記）、Windows タイトルバーと foobar2000 メニューバーの表示 / 非表示、
  foobar2000 の設定、foobar2000 メインメニュー、スキンの言語、アクセントカラー、
  壁紙、インターフェースの配色、最後に「作者の GitHub プロジェクト（リリース）」（ブラウザーでプロジェクトの
  公開リリースページを開きます）。その右に最小化、最大化、電源ボタン（foobar2000 を終了）があります。
ミニプレーヤー
- メニュー ☰ → ミニプレーヤー：ウィンドウが画面右上の小さなプレーヤーになります。
  ジャケット、曲名、アーティスト、再生順、前の曲、再生 / 一時停止、次の曲、出力デバイス、
  シークバー。タイトル部分をドラッグして移動、ハートで Favorites に追加。右上のボタン
  （またはタイトルのダブルクリック）で元の大きさのウィンドウに戻ります。ライト / ダーク
  の配色にも従います。
サイドバー（左）
- 行をクリックすると中央のリストに表示します。Music Library、Favorites、
  Search Result は上に固定され、その下に自分のプレイリストが並びます。
- Ctrl + クリックで 1 つずつ選択 / 解除、Shift + クリックで範囲選択（中央に表示
  中のリストは変わりません）。Delete で選択したプレイリストを、選択がなければ現在の
  リストを削除します。普通のクリックで選択は解除されます。再生中・ロック中・キューが
  参照しているリストは削除されません。
- 右クリック：新しいプレイリストを作成、プレイリスト名を変更、プレイリストを複製、
  プレイリストを削除、音楽フォルダーを追加。
- エクスプローラーからファイルやフォルダーをプレイリストの行にドロップするとそこに
  追加され、行の下の空白にドロップすると新しいプレイリストを作ります。
中央リスト（GLASS モード）
- クリックで選択、Ctrl + クリック / Shift + クリックで追加選択、ダブルクリックで再生。
- 行のハートで Favorites に追加 / 削除します。「…」（または右クリック）でメニュー：
  選択曲を再生キューに追加、選択曲をプレイリストから
  削除（ファイルは保持）、および foobar2000 自身の曲コマンド。
- Delete で選択曲をプレイリストから削除します（ファイルは削除しません）。
- 曲をサイドバーのプレイリストやキューへドラッグできます。エクスプローラーからの
  ファイルのドロップで追加。マウスホイールでスクロール。
右側
- 上のカードに再生中の曲（ジャケット、タイトル、アーティスト、アルバム）を表示します。
- 歌詞：現在の行が強調されます。歌詞を上下にドラッグして離す（または行をクリック
  する）とその位置へ移動します。時間情報のない歌詞はホイールでスクロール。
  右クリック：この曲だけ歌詞を 0.5 秒早く / 遅く、歌詞のずれをリセット、再読み込み、
  歌詞ファイルの場所を開く、歌詞の読み込み元（タグ、ESLyric のフォルダー、曲の
  フォルダー、指定したフォルダー）の選択、ESLyric のコマンド。
- QUEUE（右下）で歌詞の位置に再生キューを表示します。行を別の行へドラッグして並べ
  替え、ゴミ箱へドラッグして削除。キュー右上のボタンでクリア。右クリックで
  上へ移動 / 下へ移動 / キューから削除 / 再生キューをクリア。曲やファイルを
  ドロップするとキューに追加されます。
- Desk（右下）で ESLyric のデスクトップ歌詞をオン / オフします（ESLyric が必要）。
  右クリックで ESLyric のコマンドを設定します。
下部バー
- 左から：再生順（通常再生、プレイリストをリピート、1曲リピート、ランダム、
  曲をシャッフル、アルバムをシャッフル）、5 秒戻る、前の曲、再生 / 一時停止、
  次の曲、5 秒進む、出力デバイス。
- シークバーと音量：クリックまたはドラッグ。マウスホイールで 5 秒 / 2.5 dB ずつ。
元に戻すとキーボード
- プレイリスト、曲、キューの項目を削除すると、8 秒間「元に戻す」通知が出ます。
- Ctrl+Z で直前の削除を元に戻します（続けて押すとさらに前へ、パネルごとに最大
  20 回）。フォーカスがサイドバー、中央リスト、キューにあるときに使えます。検索
  ボックスでは使えません。
- Delete：選択したプレイリスト（サイドバー）または選択曲（中央リスト）を削除。

機能
- GLASS リスト：アルバムごとにまとめた透明なプレイリスト。ジャケット、反射、曲ごとの
  ハート付き。
- ミニプレーヤー：ジャケット、曲情報、再生操作、シークバーの小さなウィンドウ（メニュー ☰）。
- サイドバー：アーティスト（ライブラリから分類）またはプレイリスト。Music Library、
  Favorites、Search Result は上に固定。プレイリストの作成、名前変更、複製、削除、
  フォルダーの追加、複数選択ができます。
- どこでもドラッグ＆ドロップ：曲をプレイリストやキューへ、ファイルやフォルダーを
  エクスプローラーからプレイリスト、中央リスト、キュー、新しいプレイリストへ。
  追加した曲は並べ替えられ、重複はスキップされます。
- 上部バーからライブラリを検索。結果は Search Result に入ります。
- お気に入り：曲や再生中カードのハート。
- 再生キューパネル：ドラッグで並べ替え、ゴミ箱で削除、クリア、曲やファイルの
  ドロップで追加。
- 再生中カード：ジャケット、タイトル、アーティスト、アルバム、年、ジャンル、形式。
- 歌詞：同期歌詞と通常の歌詞。ESLyric が保存したファイル、曲のフォルダー、指定した
  フォルダー、タグから読み込みます。ドラッグで行へ移動、曲ごとに 0.5 秒早く / 遅く、
  ESLyric のデスクトップ歌詞のオン / オフ（Desk）。
- 下部バー：再生順、5 秒戻る / 進む、前の曲、再生 / 一時停止、次の曲、出力デバイス、
  シークバー、音量。
- 元に戻す：削除したプレイリスト、曲、キューの項目を 8 秒の通知または Ctrl+Z で復元。
- メニュー ☰ → アクセントカラー：images\controls のフォルダーごとに 1 色、フォルダー名で
  表示（同梱は amber、blue、mint、pink、teal、violet の 6 色）。フォルダーをコピーして
  画像と theme.json を変えると追加されます。角、枠、ボタン、文字は選んだ色になります。
- メニュー ☰ → 壁紙：スキンフォルダーの images\wallpapers にある .jpg / .png / .bmp を
  ファイル名で表示（Hariiro_UI の壁紙 2 枚を同梱）。ファイルを削除するとメニューから
  消え、使用中だった場合は別の壁紙に切り替わります。
- メニュー ☰ → インターフェースの配色：「自動」（既定）は壁紙を選んだときにその明るさを
  調べます。明るい壁紙ではライトな画面（淡いすりガラス、濃い文字とアイコン）、暗い壁紙
  では元のダークなガラスになります。「ダーク」「ライト」は壁紙に関係なくその配色です。
- 9 言語：English、Español、Português、简体中文、繁體中文、日本語、Français、
  Deutsch、Русский（メニュー ☰ → スキンの言語）。
- Windows タイトルバーと foobar2000 メニューバーの表示 / 非表示（メニュー ☰）。
- 再生中の CPU とメモリの使用量が少ない。
- Panels UI (reborn) と JS Panel を同梱したインストーラー。

既知の制限
- ESLyric 自身のパネルは埋め込めません。スキンは ESLyric が保存した歌詞（またはタグの
  歌詞）を表示します。オンライン検索は ESLyric で行います。
- ライトな画面には色フォルダー内の light\ サブフォルダーが必要です（同梱の色にはすべて
  あります。tools/make_light_controls.py で作れます）。ない場合は通常の画像を使います。
- foobar2000 フォルダーのパスには Windows のコードページにある文字だけを使ってください
  （英字、数字、スペースは常に安全です。例：D:\Program\foobar2000）。それ以外の文字が
  あると JS Panel がスキンのスクリプトを読めず、スキンが空白になります（例：日本語版
  Windows で簡体字中国語のフォルダー名）。
- Windows で未確認：125 % / 150 % の表示スケール、スケールの異なるモニター間での
  ウィンドウ移動、検索ボックスでの日本語 IME の未確定文字。

アップデート
- Install-Hariiro.cmd をもう一度実行します（または foobar2000 を終了してから
  Hariiro フォルダーをスキンフォルダーに上書きコピーします）。設定、プレイリスト、
  スキン独自のリストはそのまま残ります。
- Hariiro スキンが <profile>\foo_ui_panels-skins 以外の場所にある場合は、
  View > Panels UI > スキン で新しい場所を一度選んでください。
- foobar2000 のフォルダーを移動した場合、Panels UI が一度ようこそ画面を表示します。
  スキンフォルダー（foo_ui_panels-skins\Hariiro）を選び直してください。

テスト版からのアップデート
- 1.0.0 は Hariiro という名前での最初の正式版です。以前のテスト版（別の名前）の設定、
  ウィンドウのプロパティ、スキン独自のプレイリストは引き継がれません。スキンは既定値で
  起動し、独自のプレイリスト「Favorites」「Queue Buffer」「Search Results」
  「Sorted Library View」「Artist View」「Import Staging」を作成します。同じ名前の
  プレイリストがすでにあれば、スキンはそれをそのリストとして使います。
- テスト版の古いプレイリストは通常のプレイリストとして foobar2000 に残ります。
  お気に入りを残すには、古い Favorites の曲を「Favorites」にコピーしてから、不要な
  古いプレイリストを削除してください。
- テスト版に上書きせず、新しい空のスキンフォルダー（例：foo_ui_panels-skins\Hariiro）
  にインストールして Panels UI で選んでください。
