# Extra wallpapers

Put your own `.jpg`, `.png` or `.bmp` images in this folder, then choose them from
the settings menu (☰) → **Wallpaper**. The file name (without extension) is the menu label.
All images here are equal: the bundled `Anna_GLASS_UI_2560x1440.png` (default) and
`Anna_GLASS_UI2_2560x1440.png` are listed by their names and can be deleted like any other. If the image in use is deleted, the skin
switches to `Anna_GLASS_UI_2560x1440.png` or, without
it, to the first image by name.

Large images are scaled to the window; 16:9 at the window size you use looks best.
The skin's colours and glass panels are drawn on top, so a darker or calm image keeps
lyrics and lists readable.
